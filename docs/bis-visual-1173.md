# 1.17.3 原布局：装备 / 天赋显示优化

本轮只修改 `app/style.css`，保留上一轮的数据修理，不修改数据文件、推荐排序、导入串或节点坐标。

## 显示调整

- 保持页面、抽屉和内容区的原宽度，保留左侧 6 部位、右侧 8 部位、底部武器及原窄屏断点。
- 装备图标从 30px 调为 36px，收起摘要从 20px 调为 24px，继续使用随包游戏图标。
- 修正装备名称样式的选择器：实际元素是 `.im > b`，原 `.im .n` 未匹配到名称。
- 名称、部位标题更突出；属性间距、装等、首选 / 替代徽章分层；插槽与装等共用次行。
- 可折叠的部位头增加方向箭头与键盘焦点提示，保留原展开 / 收起逻辑。
- 补上榜单类别、热门天赋串、树来源与英雄树按钮的 `.on` 显示；原先部分按钮切换后外观不变。
- 强化方案选中标记、天赋已选 / 未选对比；保留 62×50 节点、24px 天赋图标和所有连线坐标。

## 独立浏览器验收

`tools/check-bis-visual.cjs` 用同一份当前数据，分别加载 **v1.17.3 样式**和**当前样式**进行对比；不读取用户的 `data/`，使用临时虚构角色，阻断远程请求。

- 600 / 1280 / 1600 / 1920px 视口 × 深色 / 浅色：8 组前后对比。
- 页面宽度、面板宽度和位置、内容区宽度完全一致，无新增横向溢出。
- 默认鲜血专精的 29 条装备内容、图标和部位顺序不变；99 个天赋节点的数据、尺寸、坐标和图标不变。
- 检查实战分布的 Enter / 空格展开收起、键盘焦点、方案切换和只读导入框。
- 对选中按钮的计算样式做断言，而不是只检查存在 `.on` 类。
- 输出修改前后真实截图到独立 TEMP 目录，覆盖装备顶部、左右栏、底部武器、实战分布、天赋方案和完整树。

可选运行（需本机 Edge、可供 Node 解析的 Playwright，以及本仓库 v1.17.3 tag）：

```powershell
$env:NODE_PATH="$env:TEMP\wowaltboard-browser-qa\node_modules"
node tools/check-bis-visual.cjs
```

该测试不加入运行时依赖，并从发布包排除。另运行 `node tools/run-tests.js` 与 `node tools/check-talent-browser.cjs`，确保原功能和上一轮数据隔离没有回退。
