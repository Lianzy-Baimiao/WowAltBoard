# 毕业装备 / 天赋：页签样式与易用性调整

日期：2026-10-04。基于 v1.17.3 及已完成的数据修理增量修改。

## 不变的部分

- 不修改页面/面板宽度：`#bis` 仍为 `clamp(320px, 84vw, 1160px)`，内容区左右 padding 仍为 14px。
- 保留装备图标、左 6 / 右 8 / 底部武器布局、装备排序、天赋节点尺寸与坐标。
- 不替换随包数据，不新增抓取，不把热门度、攻略推荐或 SIMC 结果宣称为最优解。
- 保留此前插件坏天赋的隔离和更新发布保护。

## 本轮已实施

### Tab 换为轻页签

上一版的描边小按钮与职业色点已撤掉。所有选择组改用无圆角/无外框的文字页签，以底部选中线和轻底色表示选中；复制、更新等操作按钮仍单独区分。

职业名称直接使用职业色，深色底适当提亮、浅色底适当压暗，避免死亡骑士红字或牧师白字看不清。长方案仍一行一个，不压缩成长短不一的小按钮。

共用 `choiceButton()`，保留 `aria-pressed`、原生 Enter/空格操作、焦点轮廓与窄屏换行。没有冒充未实现方向键导航的 ARIA tab。

### 1. 当前树与复制入口对应

- 树旁显示「当前树：来源 + 方案/榜单序号」，提供对应复制。
- 使用实际渲染分支决定复制内容，而不是只读请求的来源开关。
- 榜单串解码失败或专精不符时回退攻略，树旁复制也随实际树回退；两边均无法画树则不显示当前树复制。
- 多英雄打包明确标注「复制来源原串（含多英雄）」：原串未改写成当前单英雄树，不冒充一键精确导出。
- 插件兜底树没有对应导入串，明确说明，不拿榜单串代替。
- 两个原来源保留各自复制入口，分别叫「复制榜单原串」「复制攻略原串」。

### 2. 收起长串和技术说明

- 两个长串和导入技术说明默认放入「查看原串与导入说明」折叠块。
- 复制、人数、字符数、少样本和多英雄警告仍直接可见。
- 展开后仍可手动选择只读原串；两个来源各用独立的折叠状态键。
- 关闭的详情与复制同行，不扩大页面宽度。
- 固定夹具（鲜血、1600×1100、默认方案）第一棵树从内容顶部 **828px → 706px**；这是该夹具的测量值，不代表所有专精。

### 4. 明确装等口径

装备装等旁增加「实测最高 / 榜单均值」短标签，保留数字、升级上限和原来源提示。没有数据的项仍为「装等 ?」，不推算所谓毕业装等，不生成虚构提升比例。

### 同步修正更新入口的冲突说明

- 改为「数据来源与更新」，按文件显示自己的数据标注日期、加载位置和结果；未提供日期就明确写未提供。
- 区分包内、远端副本、远端失败回退包内、加载失败、未按需加载。折叠标题也显示回退/失败数量。
- 「重新加载远端副本」只影响当前会话，不写盘，不承诺源站最新；点击时间不会替代数据日期。
- 本地脚本成功/失败/跳过的含义单独解释；maxroll 自动抓取停用、保留快照的策略直接展示。
- 移除“页面自己拉不了”的冲突说明以及纯文本中的 Markdown 星号。
- 状态变化只刷新状态区域，不额外重建整棵树。

## 验证

新增独立 `tools/check-bis-usability.cjs`，先在旧 UI 上验证失败，再实现：

- 实际浏览器检查无框页签、无职业色点、面板 1160px。
- 长串默认折叠且复制可见、两个来源的折叠状态互不串扰。
- 树旁复制逐字符比对；复制串解码后的节点选中/rank 与当前 DOM 比对。
- 切榜单序号、解码失败回退、两边都失败、多英雄切换、插件兜底。
- 原始数据日期/未知日期、全本地加载、模拟远端成功+本地回退混合结果、远端和本地都缺失的失败状态。
- 远端测试仅用拦截请求与随包公开夹具，不访问真实源站、不读个人 `data/`。
- 输出深浅色装备/天赋以及来源状态截图，已目视检查。

`check-bis-tabs.cjs` 更新了被用户否决的旧皮肤契约：8 类选择组的共用外观、13 种职业文字色、4 皮肤 × 深浅色、选中/hover、窄屏换行均检查。没有保留旧色点断言。

`check-bis-visual.cjs` 在 600 / 1280 / 1600 / 1920px、深浅色下与 v1.17.3 CSS 对照，页面/面板/内容区宽度不变，默认夹具仍为 29 件装备 / 99 个天赋节点，图标与节点内容未改。

运行：

```powershell
$env:NODE_PATH="$env:TEMP\wowaltboard-browser-qa\node_modules"
node tools/check-bis-usability.cjs
node tools/check-bis-tabs.cjs
node tools/check-bis-visual.cjs
node tools/check-talent-browser.cjs
node tools/run-tests.js
```

以上均通过。全套回归为 139 项基础测试加渲染、数据格式、数据修理等检查；116 个变异锚点全部有效。旧回归只同步新按钮文案和装等附加标签，不降低数字/排序/复制内容校验。

## 本轮未扩展

原建议第 3 项「整页重绘后保留键盘焦点」未实施。`render()` 仍会重建按钮；测试继续记录 `focusLostOnSwitch`，没有将已知行为伪装成已修复。

本轮没有进行游戏客户端内的导入验证，也没有重新抓取/核实源站最新数据；当前树复制和数据状态的验收范围为随包数据与浏览器行为。
