# v1.18.1 — 修复首页版本显示错误

## 修复内容

- 修复升级应用后首页仍显示 1.17.3 的问题：此前误把保留角色快照中的扫描工具版本当成了当前应用版本，并不代表升级失败。
- 首页、设置中的应用说明和更新版本比较统一读取实际应用版本。普通浏览器模式使用随包发布的版本信息，不依赖联网或重新扫描。
- 扫描工具版本仍保留在悬停说明中，明确区分应用版本和数据生成版本；已下载但尚未安装的新版本不会被误标为当前版本。
- 构建完整包与增量组件时自动写入发布版本，避免后续版本标识遗漏。
- 不改写角色数据，不要求重新扫描，不改变页面宽度、Tab 样式、装备栏布局或图标；本次没有重新抓取装备、天赋等游戏数据。

## 如何升级

- **当前使用 v1.18.0：设置 → 其他 → 应用更新 → 检查应用更新**，下载完成后确认「重启并安装更新」。只下载变化的组件，保留角色数据和个人配置。
- 首次使用、浏览器模式或 v1.17.3 及更早版本：下载 **`WowAltBoard-v1.18.1.zip`**。手动覆盖前请退出应用并备份旧目录，保留原来的 `data/` 和 `tools/config.json`，不要用包内空配置覆盖个人配置。
- 不要下载 GitHub 自动生成的 Source code 作为应用安装包。`app-release.json` 与 `update-*.zip` 是应用更新器附件，不需要手动逐个下载。

- 66 项独立更新器检查及浏览器更新交互检查通过。
