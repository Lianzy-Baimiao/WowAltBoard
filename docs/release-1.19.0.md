## 12.1.5 / AlterEgo 1.6.6 适配

- AlterEgo 1.6.6 把副本、团本、赛季等数据表挪进了 `Libs\LiqUI\Data\`。旧版扫描读不到，主表会出现赛季显示成「S18」、大秘境列没有缩写且顺序乱掉、团本列变成「#3004」这类编号。本版两种目录结构都能读，以新位置为准。

- 这些表在扫描时读取，所以升级后要**重新扫描一次**，主表才会按新表重建。用 `魔兽看板.exe` 安装更新后会自动重启，重启时就会扫描。浏览器模式或手动覆盖的话，托盘右键选「立即重新扫描」。角色数据不会丢。

## 如何升级

- **当前使用 v1.18.0 / v1.18.1：设置 → 其他 → 应用更新 → 检查应用更新**，下载完成后确认「重启并安装更新」。只会下载有变化的组件，角色数据和个人配置都保留，重启后会自动重新扫描。
- 首次使用、浏览器模式，或者 v1.17.3 及更早版本：下载 **`WowAltBoard-v1.19.0.zip`**。手动覆盖前先退出应用、备份旧目录。保留原来的 `data/` 和 `tools/config.json`，不要用包里的空配置覆盖个人配置。
- 不要拿 GitHub 自动生成的 Source code 当安装包。`app-release.json` 和 `update-*.zip` 是应用更新器用的附件，不用手动下载。
