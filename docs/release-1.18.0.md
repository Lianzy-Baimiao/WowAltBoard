# v1.18.0 — 整个应用增量更新与天赋界面修复

## 下载与首次升级

- **首次使用 / v1.17.3 及更早版本：下载 `WowAltBoard-v1.18.0.zip`**，不是 GitHub 自动生成的 Source code，也不是 `update-*.zip`。
- 老用户先退出看板并备份旧目录，再用完整包覆盖应用文件；**保留原来的 `data/` 和 `tools/config.json`，不要用包内空配置覆盖个人配置**。
- 本版首次加入应用内更新器；以后在 **设置 → 其他 → 应用更新** 检查、下载并确认重启安装，不必反复下载完整包。

## 整个应用更新

- 覆盖界面、启动器、原生窗口、扫描工具、随版本发布的装备/天赋数据、图标和文档，不仅是装备数据。
- 按组件增量下载，未变化组件复用本地；支持取消与重试，校验每个包和文件的 SHA-256。
- 可选自动检查并后台下载，默认关闭，仅应用运行时每 24 小时最多检查一次。
- **不会自动安装或强制重启**：下载后可以继续使用，确认「重启并安装更新」才替换应用文件。
- 保留角色数据、设置、游戏路径和窗口状态；安装失败支持事务恢复，并保留一次应用版本回退。
- 托盘「检查更新」在原生窗口模式下直接进入应用更新；浏览器模式保留完整包下载入口。

## 天赋、装备与界面

- 在 v1.17.3 布局基础上修复无效天赋引用与解码校验，数据生成验证失败时保留原有可用文件。
- 统一 Tab 为文字加底部指示线；保留原有图标、角色装备栏排列和页面宽度。
- 天赋复制与当前显示方案保持一致，收起冗长导入内容；补充装等口径、各来源实际日期和加载状态。
- 改善窗口位置、大小及托盘恢复行为。
- 本次没有重新抓取游戏数据；应用版本不等于数据来源已最新，也不把热门配装或 SIMC 数据宣称为最优解。

## 验证与附件说明

通过原有 139 项测试及相关校验、66 项独立更新器检查（含实际进程退出、替换、重启与中断恢复）和真实 Edge 页面交互检查。

`app-release.json` 和全部 `update-*.zip` 是应用更新器使用的附件，普通用户不需要逐个下载。SHA-256 用于完整性校验，不等同于发布者数字签名；更新源固定为本仓库的 HTTPS GitHub Releases。
