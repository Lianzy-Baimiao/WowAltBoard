# SimulationCraft 衍生数据 / SimulationCraft-derived data

## 中文

`app/simc-data.js` 由 `tools/fetch-simc.js` 从 SimulationCraft 的默认配置文件生成：

- 来源：<https://github.com/simulationcraft/simc>，`profiles/MID2/*.simc`
- 提交：见 `app/simc-data.js` 文件头和其中的 `commit` 字段。对应的源文件在
  `https://github.com/simulationcraft/simc/tree/<commit>/profiles/MID2`。
- 许可：GNU General Public License v3.0，全文见 [LICENSE-GPL-3.0.md](LICENSE-GPL-3.0.md)。

这份数据按 GPL-3.0 发布。看板的其余部分仍按仓库根目录的 MIT 许可发布，两者只是放在同一个发布包里。

生成时的改动：只保留装备（物品、装等、附魔、宝石、制造副属性）、天赋导入串和配置名，动作列表、消耗品等没有收录；
没写装等的部位按 bonus_id 查表补了装等（见 `ilvlByBonus` 字段）；物品和附魔的中文名来自暴雪 DB2，不来自 SimC。

## English

`app/simc-data.js` is generated by `tools/fetch-simc.js` from SimulationCraft's default profiles:

- Source: <https://github.com/simulationcraft/simc>, `profiles/MID2/*.simc`
- Commit: see the header of `app/simc-data.js` and its `commit` field. The corresponding source files are at
  `https://github.com/simulationcraft/simc/tree/<commit>/profiles/MID2`.
- License: GNU General Public License v3.0; full text in [LICENSE-GPL-3.0.md](LICENSE-GPL-3.0.md).

This data is distributed under GPL-3.0. The rest of WowAltBoard remains under the MIT license in the repository root;
the two are only shipped together in the same package.

Changes made when generating: only gear (items, item levels, enchants, gems, crafted secondary stats), talent import
strings and profile names are kept; action lists, consumables and the rest are left out. Slots without an item level
get one looked up from their bonus IDs (see the `ilvlByBonus` field). Chinese item and enchant names come from
Blizzard's DB2 tables, not from SimulationCraft.
